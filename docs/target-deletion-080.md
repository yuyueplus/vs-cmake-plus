# Delete a target directory — 0.8.0

Select an independent target directory in **Files**, or its target node in **Targets**, then choose **Delete to Recycle Bin…**. The preview names the target, lists files to recycle, and shows all affected scripts before and after editing.

The operation removes one unconditional `add_subdirectory` entry and direct references to the target in `target_link_libraries` and `add_dependencies`. Empty dependency commands are removed. Other targets and files remain. The directory is then sent to Windows Recycle Bin using the existing deletion and recovery pipeline.

Supported directories declare exactly one configured executable, static library, or shared library in their own CMakeLists.txt. Their script must use direct target declarations and supported target-specific commands. This includes directories generated by New Target. All declared sources must be inside the directory and unused by other targets.

Root projects, shared target directories, nested CMake scripts, Presets, imported/alias targets, conditional parent references, unresolved dependencies, and additional script side effects require manual removal. Direct target references in other commands are rejected. The plugin does not rewrite C++ calls, includes, or runtime paths; removing a library still used by source code can require code changes.

Save related documents and use a fresh configured model before deleting. The operation checks file hashes and script contents again before applying. To recover, restore the original directory from Windows Recycle Bin first, then select **Recover Last File Operation…** to restore its CMake entry and dependencies. If Windows cannot recycle the directory or proposes permanent deletion, cancel.
