# 0.6.0 删除文件与目录

在文件树选中文件或目录，右键选择“删除到回收站…”，也可以使用工具栏“+”菜单。预览显示完整路径、文件数量及受影响 CMake 脚本的前后内容。按“删除到回收站”后执行；关闭预览则不修改。

需要先保存相关编辑器文档，且 CMake 模型未过期。插件同步移除直接源码引用后调用 Windows 回收站操作，再等待 VS 重新配置。Windows 可能显示自己的确认窗口；若提示无法回收或永久删除，应取消。仅支持本机固定磁盘。

保护范围：不删除工程根目录、CMake 脚本、含脚本或 Presets 的目录、生成文件或目录链接。涉及复杂变量/条件引用时拒绝操作；若删除使任一配置中的相关目标没有可识别的可编译源码，也会拒绝。不会修改 C++ 的 #include 或运行时路径。

恢复顺序：先在 Windows 回收站还原到原路径，再使用“恢复最近文件操作…”恢复 CMake 引用。插件会核对原文件内容和脚本，拒绝覆盖后续修改。不能通过编辑器 Ctrl+Z 撤销磁盘删除。回收站被清空后，插件没有文件内容备份。

回收取消时，如果原文件完整且脚本未再次变化，自动恢复脚本。若目录发生部分回收或其他并发修改，会保留恢复日志并提示处理方式；跨文件操作不是断电原子事务。日志位于 `%LOCALAPPDATA%\CMakePlus\operations`。

当前磁盘删除流程要求相关 CMake 脚本为 UTF-8 无 BOM，与移动/恢复一致。

验证：119 项核心/集成检查通过，包含三种工程删除附加源码后真实 CMake 重新配置、模型检查和 MSVC 构建。删除测试通过隔离目录模拟回收动作，覆盖取消回滚、冲突、共享引用、最后源码保护、目录还原；没有将此计为 Windows 回收站或 VS 原生界面的端到端实测。
